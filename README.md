# a-lafon/homebrew-tap

Homebrew tap for:

- [Jalon](https://github.com/a-lafon/jalon), a context advisor for AI coding agents.

      brew install a-lafon/tap/jalon

- [postgres-dba-mcp](https://github.com/a-lafon/postgres-dba-mcp), a Postgres MCP server with compact, bounded output.

      brew install a-lafon/tap/postgres-dba-mcp

The casks are written by each project's releases: do not edit them by hand.
